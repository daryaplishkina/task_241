# Настраиваем
### 1. Какой порт по умолчанию использует SSH?
По умолчанию для SSH-подключения используется порт `22`.
### 2. Можно ли изменить его? Если да — как?
Да, для этого нужно отредактировать файл конфигурации SSH-сервера, а именно раскомментировать директиву `Port` и изменить значение `22` на нужное.

Открыть файл конфигурации:
```shell
   nano /etc/ssh/sshd_config
```
Найти строку:
```shell
#Port 22
```
Раскомментировать и изменить номер

Сохранить файл и перезапустить службу:
```shell
systemctl restart sshd
```
### 3. Какая служба отвечает за обработку входящих SSH-подключений?
За обработку SSH-подключений отвечает служба `sshd` (Secure Shell Daemon)


### 4. Какой файл конфигурации отвечает за настройку SSH-сервера?
Для настройки SSH-подключения используются два основных файла: /etc/ssh/sshd_config для глобальных настроек сервера и ~/.ssh/config для индивидуальных настроек конкретного пользователя, а клиентские настройки (для подключения) также хранятся в /etc/ssh/ssh_config.
